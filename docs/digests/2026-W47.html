Thermo-VLA: A Thermal-Aware Vision-Language-Action Model with Gated Residual Modulation for Robotic Manipulation

Jingxuan Chen, Junshi Luo, Chencheng Dong et al.  ·  2026-11-09

A VLA model using language-conditioned gated residual modulation to integrate decomposed thermal attributes into RGB vision tokens.

ProblemTreating thermal data as standard visual input limits a robot's ability to perform relational reasoning based on temperature.ApproachEmploys a ThermoRes Encoder to split thermal data into cold and hot representations. These are fused with RGB tokens through gated residual modulation, enabling precise temperature-driven action generation.ResultOutperformed the pi_0.5 baseline by 18% with an 86% average success rate across thermal-dependent manipulation tasks.Why it mattersProvides a robust architectural framework for incorporating non-visual sensory modalities into VLAs beyond simple input concatenation.

APS-VLA: Action-Guided and Future-Aware Token Pruning for Efficient Vision-Language-Action Models

Xiaoyang Xing, Chun-Mei Feng, Anthony Cohn et al.  ·  2026-11-09

Accelerates VLA inference by pruning visual tokens using a lightweight, action-guided, and future-aware decision influence estimator.

ProblemDense visual tokens in VLAs cause high inference latency, and existing pruning methods fail to capture task-relevant dynamics.ApproachUses a Decision Influence Estimator trained with action supervision and visual transition objectives to select tokens while freezing the VLA. The estimator predicts which tokens most influence action generation and future state representation.ResultAchieved a 1.47x speedup, reducing latency from 137.25ms to 93.25ms with a 61% success rate compared to 60% for unpruned models.Why it mattersProvides a modular, plug-in framework for real-time VLA deployment that maintains performance without requiring expensive retraining of the core policy.

Decoupled Asynchronous System for Humanoids (DASH): Latency-Agnostic Scaling of Vision-Language-Action Models for Humanoid Manipulation

Bingzhang Wang, Nathan Zhao, Jialeng Ni et al.  ·  2026-11-09

Decouples slow VLM backbones from fast action heads to maintain 20Hz control regardless of model size.

ProblemSynchronous VLA inference creates latency-induced observation staleness, forcing a trade-off between model capacity and real-time control frequency.ApproachSplits the policy into an asynchronous System 2 VLM and a fast System 1 flow-matching action head. The action head fuses stale semantic tokens with fresh visual features using desynchronized training and adaptive temporal aggregation.ResultMaintains 20Hz control from 0.8B to 8B parameters, while synchronous baselines drop to 4.1Hz with lower success rates.Why it mattersProvides a scalable architecture for integrating massive VLMs into humanoid control without sacrificing reactivity or real-time performance.

What Makes a VLA Reactive? A Study of Execution Strategies for Dynamic Manipulation

Zhuoyue Li, Zhendong Han, Pankhuri Vanjani et al.  ·  2026-11-11

Evaluates VLA reactivity by optimizing prediction/execution horizons and inference pipelines for dynamic robot manipulation.

ProblemAction chunking in VLAs causes stale trajectories in dynamic environments as objects move during execution. Standard inference pipelines fail to maintain reactivity during the latency between observation and action.ApproachBenchmarks Pi-0.5 across varying horizons and asynchronous inference modes to decouple computation from control. Evaluates trajectory continuity methods and policy adaptation using motion cues and latent-space reinforcement learning.ResultOptimal prediction horizons are approximately 1s, and maintaining trajectory continuity is more effective than solely reducing latency. Tuning execution parameters can improve performance as much as specific policy fine-tuning.Why it mattersProves reactivity depends equally on the execution pipeline and the policy architecture. Provides a framework for selecting chunk sizes and inference strategies in real-time robot control.

Learning Low-Latency Action Verification for Frozen Vision-Language-Action Models

Wen-Han Hsieh, Ken Jiankun Zheng, Chia-Chien Chen et al.  ·  2026-11-10

A lightweight verifier trained on hindsight data ranks VLA action candidates to improve success rates with minimal latency.

ProblemSampled VLA action sequences frequently fail, and standard verification methods introduce prohibitive computational overhead during real-time robotic inference.ApproachTrains a compact success-prediction head using autonomous rollouts from a frozen VLA. During execution, the VLA generates multiple candidate action chunks, which the verifier ranks to select the optimal trajectory.ResultAchieved 82.3% average success on LIBERO-10 and improved real-world manipulation success rates by 22.6% over baseline policies.Why it mattersEnables test-time action selection and error mitigation for large pre-trained VLAs without the cost of full model fine-tuning or heavy re-ranking architectures.

VLA Adaptation with Real and Simulated Data: A Case Study on Robotic Chess

Matěj Kripner, Milan Straka  ·  2026-11-09

Evaluates VLA fine-tuning strategies for precise manipulation, emphasizing sim-to-real pretraining and the impact of learning-rate cool-down.

ProblemAdapting VLAs to high-precision spatial tasks is data-intensive, and standard offline metrics like validation loss are unreliable for model selection.ApproachFine-tuned the pi_0.5 model using real teleoperated and randomized simulated chess demonstrations. Evaluated sim-to-real transfer, learning-rate cool-down schedules, and self-improvement methods including RECAP-style advantage conditioning and residual RL.ResultSimulated pretraining significantly boosts performance with scarce real data, while a learning-rate cool-down adds up to 31 success points; offline metrics failed to correlate with success.Why it mattersProvides practical evidence that sim-to-real pretraining and specific LR schedules are more effective for VLA adaptation than advanced self-improvement or residual RL techniques.

Inner Product Regularization for Imitation Learning

Benjamin A. Christie, Tianyu Qiu, Amy H. Choi et al.  ·  2026-11-12

Regularizes imitation learning by aligning policy Jacobian null spaces across nearby states to ensure consistent responses to perturbations.

ProblemImitation learning policies lack robustness to noise and distribution shifts because they fail to maintain consistent action sensitivities across similar states.ApproachComputes state-space inner products using policy Jacobians, clusters states by alignment, and minimizes averaged smallest eigenvalues. This enforces a shared null space across local regions, making the policy invariant to irrelevant state perturbations.ResultIncreased real-world diffusion policy success rates from 18% to 57% while outperforming standard norm-based regularization in noise rejection.Why it mattersProvides a mathematically grounded regularizer to improve OOD robustness and noise rejection in high-dimensional robot policies like diffusion models.

Yilong Song, Harshvardhan Chandirasekar, Karthik Desingh et al.  ·  2026-11-11

Augments robot datasets by crowdsourcing multiple valid alternative actions per state via a web-based 3D annotation interface.

ProblemPhysical robot demonstrations are expensive and provide sparse supervision with only one action label per visited state.ApproachRemote non-experts use a 3D interface to provide multiple valid alternative keyframe goal-poses for existing trajectory states. Automated flywheel aligning LLM reasoning and VLA execution through iterative environmental interaction and cross-module supervision.

ProblemUncoordinated behavior occurs when VLA actions diverge from LLM subtask intent or undo state progress made during LLM corrections.ApproachRefines prompts and VLA parameters by using LLM subtasks as semantic supervision and LLM corrections as action-level recovery data. An autonomous data engine using coding agents to generate targeted demonstrations for failure-driven VLA post-training via environment interaction.
