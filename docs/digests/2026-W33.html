In-Context VLA: Endowing Vision-Language-Action Models with Language via In-Context Post-Training and Agentic Tool Use

Jiarui Yang, Wen Huang, Jiale Zhang et al.  ·  2026-08-06

Endows VLAs with language competence using structured in-context perceptual evidence and agentic tool-use instead of narrative reasoning.

ProblemTextual chain-of-thought (CoT) in VLAs degrades control through ungrounded reasoning, inference latency, and conflicting optimization objectives.ApproachIn-context post-training injects structured spatial evidence from vision tools as prompts while supervising only on actions. The framework uses agentic tool-use to generate diverse, paraphrased spatial descriptions as task-relevant context for the policy.ResultReaches SOTA benchmarks on RoboCasa-GR1, SimplerEnv, LIBERO, and 8 real-world tasks, outperforming CoT-based methods in success and efficiency.Why it mattersFixes the narration-action misalignment in CoT-VLAs by treating language as a grounded input modality rather than an output.

A 3D VLA framework combining multi-view projection with spatio-temporal memory for data-efficient and memory-dependent robot manipulation.

Problem3D VLA models suffer from high data requirements and lack explicit memory, hindering performance in complex, history-dependent manipulation scenarios.ApproachProjects 3D point clouds into multi-view images to leverage pre-trained VLM alignments while predicting intermediate heatmaps for spatial grounding. Integrates a unified spatio-temporal memory architecture to model persistent context and temporal interaction history.ResultAchieved state-of-the-art results on two memory-dependent benchmarks and successfully transferred to bimanual and real-world platforms without sacrificing data efficiency.Why it mattersAddresses the 3D data-scarcity bottleneck and memory limitations in robot learning by bridging pre-trained VLMs with 3D spatial reasoning.

AtlasVLA: Persistent World-Ego State Modeling for Vision-Language-Action Models

Guiyu Zhao, Longteng Guo, Yanghong Mei et al.  ·  2026-08-07

Persistent world-ego state modeling via 4D voxel-hashed memory and temporal tracking for robust, long-horizon single-camera manipulation.

ProblemReactive VLA models suffer from perception and task-progress forgetting in long-horizon tasks, particularly when objects exit the wrist-camera field-of-view.ApproachIntegrates a 4D Persistent World State Memory using voxel hashing for 3D reconstruction and an Ego-Working State Memory for task tracking. Mind-VLA: Instruction-Aware Spatial Representation Alignment for Vision-Language-Action Models

Xingyu Ding, Yuzhong Zhao, Yang Wu et al.  ·  2026-08-05

Aligns VLA latent representations with instruction-specific 3D target geometry via tri-view features for robust manipulation.

ProblemExisting VLAs use instruction-agnostic 3D scene alignment, failing in fine-grained tasks and occlusions where target-specific geometric understanding is critical. Uniform scene alignment neglects the precise spatial characteristics of the specific object designated by the language prompt.ApproachExtract the instruction-specified target object and generate its tri-view representation. Align the VLA's latent features with target-centric VAE and VGGT features to inject instruction-aware spatial priors into the model's bottleneck.ResultMind-VLA achieved 93.9% on LIBERO and 4.47 on CALVIN with 345M parameters, outperforming instruction-agnostic baselines by 32% in real-robot occlusion scenarios.Why it mattersDemonstrates that target-centric 3D alignment is superior to global scene alignment for VLA robustness, offering a scalable path for small models to handle complex spatial reasoning.

ValueFormer: A Causal Transformer Value Function with Stage-Aware Labels for Semi-Autonomous Vision-Language-Action Policies

Inkyu Sa, Konstantin Stulov, Rajat Bhageria  ·  2026-08-03

Causal transformer critic using stage-aware rewards to improve VLA policy performance and enable online mistake detection.

ProblemImitation-based VLA policies fail silently because they lack a notion of progress and sparse binary rewards provide insufficient supervision.ApproachValueFormer uses a causal transformer over frozen DINOv3 features to predict dual signals: smooth Monte Carlo values and binary mistakes. It employs a success-then-decay labeling strategy to preserve progress curves before failures.ResultIncreased bimanual sandwich-assembly success from 70% to 85% and reduced inference cost 3-5x via batched bf16 encoding.Why it mattersAddresses the critical need for dense reward shaping and real-time failure monitoring in real-world robot deployments without simulation.

ChainVLA: Chaining Vision-Language-Action Queries through a Unified Execution State for Long-Horizon Manipulation

Yuzhi Huang, Weijue Bu, Ziyi Xiong et al.  ·  2026-08-03

A 1.2B VLA policy chaining queries via a recurrent execution state and motion tail for long-horizon task continuity.

ProblemAction-chunked VLA policies replan from scratch every query, losing task-level progress and motion continuity across execution windows.ApproachUses a joint execution state combining Progress Context (recurrent working state and event memory) with Motion Tail (previous unexecuted actions). This state conditions a decoder to regenerate the action horizon while grounding historical task evidence in current observations.ResultAchieved 62.8% success on RMBench and 98.8% on LIBERO, significantly outperforming versions without motion continuity or task history.Why it mattersProvides a robust method for maintaining temporal consistency in transformer-based policies, essential for scaling VLAs to complex multi-step robot manipulation.

Hisham Khalil, Neil Fernandes, Thomas M. Kwok et al.  ·  2026-08-06

A framework combining Diffusion Policies with TP-DAMM to learn variable impedance and pose actions from kinematic demonstrations.

ProblemStatic compliance lacks adaptability, and kinematic variance often reflects geometric shifts rather than intended compliance in multi-layout demonstrations.ApproachExtracts physically consistent trajectory distributions using a Task-Parameterized Directionality-Aware Mixture Model. Explicit Language Memory for Long-Horizon Planning in Vision-Language-Action Models

Houze Xu, Jizhong Li, Ziyi Ye  ·  2026-08-05

Hierarchical VLA architecture using explicit textual memory sequences to maintain temporal consistency and reasoning for long-horizon robot control.

ProblemVLAs struggle with long-horizon tasks due to limited temporal context, error accumulation, and semantic degradation during end-to-end action fine-tuning. These models often fail to maintain consistency across non-Markovian subtask sequences.ApproachA hierarchical framework decouples high-level reasoning from low-level control using an explicit language-memory module. A VLM recursively updates a textual memory sequence with temporal logic to track progress, while a low-level VLA executes continuous control conditioned on generated subtasks.ResultImproved success rates and robustness in simulation and sim-to-real experiments. The system provides interpretable semantic logs of decision-making while mitigating error accumulation through dynamic subtask correction.Why it mattersProvides a method to preserve VLM semantic reasoning capabilities while performing continuous control. The explicit memory approach effectively handles long-horizon dependencies that standard Markovian policies cannot capture.

Track4Action: Distilling World-Centric 3D Tracker into Vision-Language-Action Policies

Chenyi Wang, Xinkai Wang, Bokai Lin et al.  ·  2026-08-04

Distills 3D world-centric tracker features into VLA policies via privileged supervision for improved action-world state alignment.

ProblemStandard VLA action labels lack explicit supervision regarding how commands physically transform scene geometry, visibility, and 3D motion.ApproachEncodes demonstration clips into pooled 3D tracker features during training to supervise VLA hidden states via track queries. These features condition a flow-matching action head through feature-wise gating and are discarded during inference.ResultAchieved 82.3% on zero-shot LIBERO-Plus and 67.5% success on physical bimanual tasks, outperforming alignment-free baselines by up to 25 points.Why it mattersEnables VLA policies to internalize complex 3D world dynamics without requiring trackers or future video frames during robot deployment.

Jinquan Zhang, Dongfu Yin, Run Yang et al.  ·  2026-08-04

Defends VLA models against physical attention-hijacking patches using structure-aware fine-tuning of the visual encoder.

ProblemPhysical adversarial patches hijack action-to-vision attention and disrupt semantic alignment, causing catastrophic failure in VLA policies.ApproachStructure-Aware Robust Fine-Tuning (SARF) applies feature anchoring, policy-critical attention correction, and language-guided geometric consistency to the visual encoder. This method anchors features to semantically relevant regions to maintain clean performance while neutralizing adversarial attention sinks.ResultOn LIBERO, SARF reduced OpenVLA's failure rate under attack from 100% to 28.6% average; real-world success improved from 23% to 65%.Why it mattersEstablishes a zero-inference-overhead defense mechanism essential for securing VLA-based robotic systems against physical-world adversarial manipulation.

Harisankar Babu, Benjamin Coors, Christopher Lang et al.  ·  2026-08-07

Analyzes planning token evolution across VLA layers to enable inference speedups via depth-wise pruning and layer-specific probing.

ProblemInvestigates whether the extensive depth of transformer-based driving VLAs is computationally necessary for trajectory generation or contains significant redundancy.ApproachEmploys a trajectory-space logit lens to probe planning token representations across all 32 layers.
