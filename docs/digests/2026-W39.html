Underwater bimanual platform for learning coordinated manipulation using VLA models under complex physical and perceptual aquatic disturbances.

ProblemUnderwater robot learning is restricted to single-arm setups, ignoring bimanual coordination and specific aquatic physics like buoyancy and bubble-induced visual noise.ApproachIntegrates custom leader-follower hardware with the LeRobot framework to collect multi-view demonstrations for ACT, Diffusion Policy, and SmolVLA. Experiments focus on coordinated tasks such as inter-arm transfer and buoyancy-aware manipulation in a unified pipeline.ResultSuccessfully deployed VLA and diffusion policies for underwater bimanual tasks and proved that cross-media training enables robust policy transfer between air and water.Why it mattersOffers a specialized testbed for evaluating the robustness of VLA models and action-chunking strategies against non-standard physics and visual degradation.

IMPACT-VLA: Interaction-aware Multimodal Propagation Attribution via Counterfactual Trajectories for Vision-Language-Action Policies

Jinwoong Kim, Sangjin Park  ·  2026-09-14

Evaluates phase-dependent multimodal contributions in VLA policies via closed-loop counterfactual execution and trajectory propagation analysis.

ProblemStatic attribution methods fail to capture how multimodal inputs interact across temporal phases or how interventions propagate during closed-loop robot execution. Current approaches lack the granularity to distinguish between behavioral path recovery and functional task success.ApproachDecomposes rollouts into phase-modality blocks and executes closed-loop counterfactual trajectories to quantify each block's marginal contribution to task success. The framework analyzes cross-phase non-additive interactions and tracks how input perturbations propagate through subsequent states and actions.ResultIdentified modality shifts in 83.3% of LIBERO tasks and demonstrated that early-phase input replacements increase later-block marginal gains by 3.3x due to conditional coupling.Why it mattersProvides a diagnostic framework for VLA policies to identify task-critical execution stages and understand how multimodal failures propagate or are mitigated through closed-loop recovery.

VLA-Scope: Shift-Aware Failure Prediction for Vision-Language-Action Models

Kaiwen Zhu, Dongfang Liu, Liangkai Liu  ·  2026-09-18

A two-stage framework predicting VLA execution failure by combining input-shift characterization with action-prefix and temporal execution progress features.

ProblemDistribution shifts degrade VLA reliability, yet standard OOD detection over-rejects scenarios where models might still successfully generalize. Predicting failure requires distinguishing between benign shifts and execution-critical errors.ApproachThe system first classifies input shifts using pooled image-language representations to detect OOD states. It then employs a logistic regression model that integrates the shift category, action-prefix features, and temporal execution progress to dynamically update failure risk.ResultAchieved 0.9454 ROC-AUC for OOD detection and 0.8497 ROC-AUC for failure prediction on LIBERO-Spatial, outperforming baselines like ActProbe. Execution progress features specifically improved failure prediction from 0.7906 to 0.8497 ROC-AUC.Why it mattersProvides a runtime monitoring solution for large VLAs like OpenVLA to manage safety during deployment. It highlights that temporal execution context is more predictive of failure than static OOD signals alone.

Decentralized VLA training using ADMM consensus optimization to handle heterogeneous robot data without centralizing datasets.

ProblemRobot data is naturally distributed across different hardware and locations, making centralized collection costly and privacy-invasive. Heterogeneous data distributions across these clients hinder standard federated learning convergence for large VLA models.ApproachUses the Alternating Direction Method of Multipliers (ADMM) to achieve consensus optimization across decentralized robot clients. The method supports both full-parameter training and parameter-efficient fine-tuning using fixed-rank or rank-adaptive adapters.ResultAchieved performance comparable to centralized training in both full-model and PEFT settings across diverse robotic datasets. The system successfully enables collaborative learning without sharing raw trajectory data.Why it mattersEnables scaling robot foundation models using private or geographically distributed data from different robot embodiments. It provides a mathematically grounded framework for multi-site robot learning where data centralization is impractical.

A VLA model integrating vision-language features with multi-step tactile forecasting for predictive reasoning in contact-rich robotic manipulation.

ProblemStandard VLA models lack physical grounding in visually occluded, contact-rich environments and typically rely on reactive rather than predictive tactile sensing.ApproachUses a Transformer-based forecasting module to predict multi-step future tactile states from temporal embeddings.
