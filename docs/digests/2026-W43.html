NestedVLA: Learning to Consolidate and Generate Skills for Vision-Language-Action Models

Guodong Du, Wanyu Lin  ·  2026-10-16

Synthesizes task-adaptive action-expert parameters using a nested hypernetwork to consolidate diverse robotic skills without interference.

ProblemMulti-task VLA training suffers from gradient interference, while standard model merging causes parameter conflicts when consolidating skills from heterogeneous environments.ApproachA task-conditioned nested hypernetwork generates weights for an action-expert module integrated with a frozen VLA backbone. Task-specific compressed VLM residuals are stored independently, allowing for modular post-hoc skill consolidation through parameter generation rather than aggregation.ResultOutperformed model-merging baselines by 41 percentage points on average and matched per-task fine-tuning performance within 1% on ManiSkill benchmarks.Why it mattersProvides a storage-efficient, interference-free architecture for scaling VLAs to new domains without the performance degradation typical of weight averaging or joint finetuning.

Do VLAs Really Follow Instructions? Diagnosing How-Level Instruction Following in Vision-Language-Action Models

Sangwu Park, Wonjoong Kim, Yeonjun In et al.  ·  2026-10-15

Diagnoses VLA failures in following fine-grained execution instructions and introduces the SIMPLER-IN benchmark for instruction-dependent evaluation.

ProblemCurrent VLAs ignore or are degraded by 'how-level' instructions specifying execution details rather than just task goals. Training on single, coarse-grained instructions per episode limits the model's ability to ground specific actions to linguistic modifiers.ApproachEvaluated model sensitivity to 'how-level' prompts and proposed training with segment-level enriched instructions. Introduced SIMPLER-IN, a benchmark where success is strictly contingent on following specific execution constraints provided in the prompt.ResultSegment-level enrichment increases action responsiveness to detailed instructions but does not consistently improve task success or generalize to out-of-distribution commands. 'How-level' instruction following remains a significant open challenge for current VLA architectures.Why it mattersPrecise robotic control requires models to respect safety and stylistic constraints. This work highlights a critical gap in VLA controllability that prevents reliable deployment in complex, constraint-heavy environments.

TacitVLA: Reasoning Vision-Language-Action Models Without Reasoning Latency

Jack Lu, Yurong You, Boyi Li et al.  ·  2026-10-13

Decouples reasoning generation from action execution in VLAs to eliminate Chain-of-Thought latency without sacrificing performance gains.

ProblemExplicit textual reasoning improves VLA performance but introduces high inference latency because action generation must wait for sequential autoregressive decoding of reasoning tokens.ApproachUses multi-task supervision where the model generates both reasoning and actions, but the action head is architecturally restricted from attending to current-step reasoning tokens. This forces the shared backbone to internalize reasoning logic into its representations, allowing actions to benefit from 'tacit' reasoning while generating text in parallel.ResultMatches explicit reasoning performance with 3.4x lower latency and outperforms non-reasoning baselines by up to 17.1% success rate on RMBench.Why it mattersEnables real-time deployment of high-performance reasoning VLAs by proving that the benefits of CoT reside in representation learning rather than explicit conditioning.

Fast-VLA: You Only Think Once for Robot Manipulation

Kehong Gong, Guanli Hou, Xiaoxu Zheng et al.  ·  2026-10-15

Decouples slow task contextualization from fast action generation by caching VLM key-value memory once per episode.

ProblemLarge VLA models repeatedly recompute static task and instruction context during high-frequency control loops, leading to excessive latency. This redundancy prevents large foundation models from achieving the responsiveness required for real-time robot manipulation.ApproachA 4B VLM generates multi-layer KV task memory from instructions and initial views only once per episode. A lightweight online actor then fuses real-time visual-proprioceptive feedback with time-indexed queries to retrieve relevant context from this fixed memory and predict actions.ResultReduces amortized inference time by 10.9-17.1x with 1.22 GiB memory usage, achieving 92.46% success on RoboTwin and 95.95% on LIBERO.Why it mattersProvides a scalable architecture for deploying massive VLAs in low-latency settings by separating high-level task reasoning from high-frequency motor control.
